# Changelog

## 1.2.0

- Layout full-view картки переписаний на CSS container queries: тепер
  адаптується під реальну ширину самої картки на дашборді (а не вікна
  браузера), тому на всю ширину панелі картка більше не розтягується по
  вертикалі — комірки/діагностика/ємність лягають у 2 колонки на широких
  картках і в 1 на вузьких
  зменшено паддінги/шрифти по всій картці для більш компактного вигляду
- Додано Setup Wizard у редакторі картки: кнопка автоматично створює
  helper-сенсори для відслідковування споживання (Riemann sum integral +
  3x Utility Meter: daily/weekly/monthly) і підставляє їх у конфіг картки;
  з детекцією вже створених сенсорів, щоб уникнути дублікатів
- Репозиторій приведено у відповідність до вимог HACS: заповнено опис і
  topics репозиторію на GitHub (пошук/дискавері), README/hacs.json/LICENSE
  вже відповідали вимогам і залишені без змін

## 1.1.0

- SOC тепер відображається як справжня форма акумулятора (корпус з клемою
  зверху, заповнення знизу вгору, колір залежить від рівня заряду) замість
  кільцевого гейджа — і у widget, і у full-view
- Назва батареї більше не хардкодиться: автоматично підтягується з Device
  Registry (пристрій, до якого належить сутність SOC/voltage у BMS_BLE-HA),
  з fallback на friendly_name сенсора; `name` в конфізі тепер опційний
  override, а не обов'язкове поле
- Widget-режим показує назву та Bluetooth-іконку статусу у власному заголовку

## 1.0.0 — перший реліз

- Widget-режим (компактна картка + fullscreen попап з адаптацією під
  портретну/альбомну орієнтацію)
- Inline-режим (повна картка одразу на дашборді)
- SOC, напруга, струм, потужність, температура
- Напруга комірок з configurable порогами кольорового кодування
  (`cell_delta_warning`, `cell_delta_critical`)
- Статус BMS: заряджається / розряджається / проблема
- Діагностика: балансир, MOSFET заряду/розряду, нагрівач, link quality, RSSI
- Прогноз часу роботи (runtime)
- Опційні картки використаної ємності (сьогодні/тиждень/місяць/всього) —
  потребують окремо налаштованих integration + utility_meter helpers
- GUI-редактор (базовий: назва, режим відображення)
